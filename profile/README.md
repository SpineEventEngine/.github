## Welcome to Spine Event Engine SDK

This SDK provides a set of tools, libraries, and utilities for building message-driven applications
using Domain-Driven Design (DDD) principles.

For more information on the SDK, please visit the https://spine.io website and
the [Documentation][main-documentation] section of the site.

### Examples                    

Examples are available from the dedicated [spine-examples](https://github.com/spine-examples) GitHub organization.
